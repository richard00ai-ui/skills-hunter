# Skills Hunter 项目记忆

## 产品定位
面向探索型 AI 开发者的 skills 发现与收集平台，类似 Product Hunt。

## 设计决策记录

### 卡片 vs 详情页的职责划分
**日期：2026-04-07**

- **卡片的核心职责是营销转化**，目标是吸引用户点进去，视觉冲击力优先
- **开发者实际使用的信息（安装命令、来源仓库、兼容平台等）放在详情页**
- 卡片不考虑使用层面的信息，专注视觉效果

**卡片展示字段：**
- Skill 名称
- 一句话描述
- 标签 / 分类
- 站内投票数
- 评论数
- GitHub Stars 数

**详情页展示字段（至少包含）：**
- 来源仓库（含 GitHub 跳转链接）
- 安装命令（一键复制）
- 最近更新时间
- 作者 / 提交者
- 完整描述 / SKILL.md 内容
- 评论区（论坛功能入口）
